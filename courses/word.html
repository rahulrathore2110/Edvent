Microsoft Word — Complete Master Syllabus

To learn MS Word thoroughly, you should study every Ribbon tab, every major group within each tab, and the important commands inside those groups, followed by document production, automation, and troubleshooting.

The syllabus below follows the standard desktop version of Microsoft Word, primarily Word for Windows. Word for Mac and Microsoft 365 may have different menus, commands, and feature availability. It includes the Mailings and View tabs, as well as the other standard tabs.

Complete learning roadmap

File

Create, open, save, export, print and account options

Draw

Pen, highlighter, ink and drawing tools, where available

Home

Text editing, formatting, paragraphs and styles

Insert

Pages, tables, pictures, links and document elements

Margins, page setup, indentation and spacing

References

Table of contents, citations, footnotes and indexes

Mail Merge, recipient lists, labels and envelopes

Proofreading, comments, changes and protection

View

Document views, navigation, zoom and window management

Developer

Macros, controls, forms and document automation

Advanced & Practical

Templates, fields, accessibility, shortcuts and real-world projects

Important: Some Word versions display additional tabs, such as Help, Acrobat, or contextual tabs that appear only when you select a table, picture, shape, or header. You should learn these too where they are available. No single fixed list can guarantee that every command appears in every edition, because Microsoft changes the Ribbon by version, operating system, subscription, and enabled add-ins.

1. File tab — document and file management

Learn this first at a basic level, then revisit advanced options later.

New — Create a blank document or use a template.

Open — Open recent files, browse folders, and access cloud files.

Info — Inspect document properties, protect a document, inspect it, and manage versions where available.

Save — Save changes to the current file.

Save As — Save under a new name or location.

Save a Copy — Create another version without replacing the original, where available.

Export — Create PDFs and other supported output formats.

Print — Select printer, page range, copies, orientation, paper size and other print settings.

Share — Share a document or invite collaborators, depending on account and storage.

Account — Check the signed-in account, connected services, and Office product information.

Options — Customize Word settings, proofing, save behavior, language, Ribbon and Quick Access Toolbar.

Feedback — Submit feedback if the feature is available.

Close — Close the current document.

Version History — View or restore earlier versions where supported.

14. Advanced document management and productivity

These skills go beyond individual Ribbon buttons and help you handle complex, professional documents.

Section management: Different page orientations, headers, footers and numbering within one document.

Page numbering: Roman numerals for front matter and Arabic numerals for main content.

Automatic fields: Page, NumPages, Section, FileName, Date and other field codes.

Field updating: Update fields, captions, cross-references and tables of contents.

Bookmarks: Create stable navigation points.

Automatic numbering: Maintain numbering across headings, lists, captions and appendices.

Templates: Create .dotx and macro-enabled .dotm templates.

Quick Parts: Reuse boilerplate text, document properties and building blocks.

Document properties: Author, title, subject, keywords and custom metadata.

Compatibility: Work with .docx, .doc, .docm, .dotx, .rtf, .txt and .pdf workflows.

Co-authoring: Collaborate through supported cloud storage.

Version control: Track revisions and restore earlier versions where supported.

File recovery: AutoRecover, AutoSave and recovery of unsaved documents.

Document inspection: Check hidden information and metadata before sharing.

Digital signatures: Understand signature lines and supported signing workflows.

Password protection: Protect files with encryption where supported.

Accessibility: Screen-reader-friendly headings, tables, links and alternative text.

Long documents: Manage chapters, appendices, indexes and large tables.

Cross-application workflows: Insert or link Excel data and PowerPoint objects.

Troubleshooting: Fix formatting inconsistencies, blank pages, broken numbering and layout changes.
